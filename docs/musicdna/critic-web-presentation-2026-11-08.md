- Three ranked openers retain their existing mutations; current song/reply/input replaces the growing transcript.
- Pairing stage displays progress, original generic vinyl imagery (not official album artwork), one latest read, reactions and server-selected next question. Accessible history drawer retains earlier choices and full readings.
- Reaction confirmation is inline after the durable server response, not a toast; no simulated revision.
- Reveal uses the first saved synthesis sentence as its lead, retains the full frozen text under details, and displays authorized supporting examples/counter-reads. It does not invent a stronger headline for insufficient evidence.
- Conversation opens first, with the selected saved result collapsed. Fallback replies stay verbatim; the UI explains the failure and offers optional voice/context draft prompts. Only stored messages count as replies.
